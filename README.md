# DavidRivera_IanOrellana_movil

EVALUACION PRACTICA DESARROLLO DE APLICACIONES MOVILES
FIREBASE

DAVID RIVERA
IAN ORELLANA 

Desarrollo de una aplicación móvil utilizando React Native que permita la autenticación de usuarios
mediante Firebase Auth, gestionando las credenciales de conexión de forma segura a través de variables de
entorno (.env). La aplicación esta estructurada mediante componentes reutilizables y tres
pantallas.
